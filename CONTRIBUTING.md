# Contributing to AI Flashcards Hub

First off, thank you for considering contributing to AI Flashcards Hub! ❤️

This project is built to be a welcoming and beginner-friendly environment. We strongly believe that **you don't need to be an expert to contribute to open source.**

## Your First Contribution?
If this is your first time contributing to an open-source project, you are exactly who we want! **Make it small.**

Even a one-line improvement is a valid and highly appreciated contribution. Some excellent beginner tasks include:
- Fixing a typo in the README or the flashcard content.
- Improving the wording in documentation.
- Fixing a broken link.
- Adding a screenshot to the README.
- Improving accessibility (like adding missing `aria-label` tags).
- Tweaking spacing on mobile devices.
- Suggesting a new idea or feature.

Don't feel intimidated. If you're stuck, just ask for help in an issue and we'll be happy to guide you!

## Contribution Workflow

Ready to contribute? Follow these simple steps:

1. **Fork the repository:** Click the "Fork" button at the top right of the GitHub page. This creates your own copy of the project.
2. **Clone your fork:** Download your copy to your local machine.
   ```bash
   git clone https://github.com/YOUR_USERNAME/ai-flashcards-hub.git
   ```
3. **Create a branch:** Create a new branch for your specific change. Keep the name simple and descriptive.
   ```bash
   git checkout -b docs/fix-readme-typo
   ```
   *(Other examples: `fix/mobile-navigation`, `feature/dark-mode-tweak`)*
4. **Make your change:** Edit the files in your favorite text editor.
5. **Test your change:** Open `index.html` in your browser (or run a local server like `python3 -m http.server 8080`) to ensure everything looks correct.
6. **Commit your changes:** Save your changes with a clear message.
   ```bash
   git add .
   git commit -m "docs: fix typo in getting started section"
   ```
7. **Push your branch:** Push the changes back to your fork on GitHub.
   ```bash
   git push origin docs/fix-readme-typo
   ```
8. **Open a Pull Request:** Go to the original repository and you will see a prompt to open a Pull Request. Fill out the simple template, and you're done!

## Found a bug? 🐛
If you find a bug in the source code, you can help us by submitting a Bug Report via our Issue Tracker. Even better, you can submit a Pull Request with a fix!

## Have a feature request? 🚀
We are always open to new ideas. Submit a Feature Request via the Issue Tracker, and let's discuss how it fits into the project roadmap.

Thank you again for your time and effort to improve AI Flashcards Hub!
